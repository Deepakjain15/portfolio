# Deepak Jain, portfolio

A one-page portfolio: interactive 3D map of projects and skills, selected work, journey, skills and contact.

- Plain HTML, CSS and JavaScript. No build step.
- 3D map uses [Three.js](https://threejs.org/) (loaded from cdnjs).
- Open `index.html` in a browser to view it locally.

Deployed on Vercel from this repo.
